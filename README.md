## 📢 제안 배경

1. **정보 분산으로 인한 비교의 어려움**
   - 자동차 등록 현황, 전기차 보조금, 충전소 위치 등의 정보가 여러 기관과 사이트에 분산되어 있어 사용자가 필요한 정보를 한곳에서 확인하기 어렵습니다.
2. **전기차에 대한 관심 증가**
   - 최근 전기차 신규 등록이 크게 증가하면서 자동차 구매 과정에서 전기차를 하나의 선택지로 고려하는 소비자도 증가하고 있습니다. ([관련 뉴스 기사 보기](https://m.wowtv.co.kr/NewsCenter/News/Read?articleId=A202603300193))
3. **통합 정보 제공의 필요성**
   - 실제 자동차 등록 데이터를 기반으로 지역별·연료별 현황과 전기차 보조금, 충전소 정보를 한곳에서 확인하고 비교할 수 있는 서비스가 필요하다고 판단하였습니다.

## 📈 기대효과

### 🌐 자동차 정보 접근성 향상
자동차 등록 현황, 전기차 보조금, 충전소, FAQ 등 여러 곳에 분산된 정보를 하나의 서비스에서 확인할 수 있어 정보 접근성이 향상됩니다.

### 📊 지역별·연료별 자동차 현황 비교 용이
Streamlit의 필터와 시각화 기능을 통해 연도·월·지역별 자동차 등록 현황을 쉽게 비교할 수 있어 사용자가 자동차 시장의 변화를 직관적으로 파악할 수 있습니다.

### ⚡ 전기차 구매 정보 확인 편의성 향상
전기차 등록 현황뿐만 아니라 보조금과 충전소 정보를 함께 제공하여 전기차 구매를 고려하는 사용자가 필요한 정보를 보다 편리하게 확인할 수 있습니다.

### 💡 데이터 기반 의사결정 지원
단순한 차량 추천이 아니라 실제 등록 데이터를 기반으로 정보를 제공함으로써 사용자가 다양한 차량 유형을 비교하고 자신의 조건에 맞는 선택을 검토하는 데 도움을 줄 수 있습니다.

### 🚀 향후 서비스 확장 가능성
향후 차량 가격, 유지비, 충전 비용, 연비 등의 데이터를 추가하면 사용자의 조건에 따른 차량 비교 및 분석 기능으로 확장할 수 있습니다.

## ✨ 기능

### 📊 전국 자동차 현황 & 전기차 보급 추이 대시보드
- **연료별 자동차 등록 현황:** 전국 기준 내연기관, 하이브리드, 전기차, 수소차의 현재 등록 대수 및 비중 시각화
- **기간별 전기차 등록 추이:** 시계열 데이터를 통해 국내 전기차 시장의 성장세와 친환경차 전환 속도를 한눈에 파악

### ⚖️ 서울·경기 예산 맞춤형 차량 비교 (전기차 vs 내연기관)
- **예산 범위 설정:** 사용자가 소유한 예산 및 지역선택
- **보조금 자동 산정:** 지역별전기차 보조금을 적용한 실구매가 기준 데이터 제공
- **1:1 모델 매칭 비교:** 설정한 예산 범위 내에서 구매 가능한 전기차 모델과 동급 내연기관 모델을 한 화면에서 대조하여 추천 

### 🔌 전기차 충전소 위치 검색
- **지역 및 키워드 기반 검색:** 서울·경기 및 전국 주요 지역의 전기차 충전소 위치 탐색
- **충전소 상세 정보:** 충전기 타입(급속/완속), 운영 기관, 위치 정보를 직관적인 지도/리스트로 제공 

### ❓ 내연기관 vs 전기차 카테고리별 FAQ
- **맞춤형 카테고리 분류:** '전기차' / '내연기관' 카테고리별 자주 묻는 질문 구성
- **구매 고민 해소:** 충전 요금 체계, 겨울철 주행거리 관리, 배터리 보증, 내연기관 대비 유지비 절감액 등 소비자가 자주 궁금해하는 유용한 정보 제공

## 🛠️ 프로젝트 문제 및 해결방법

### 👤 이승훈-

데이터 수집과정중 전국,서울 그리고 경기도 마다 데이터의 제공 단위가 달랐다.
- 경기도 ->'시' 단위
- 서울 ->'지자치구' 단위
- 그외 모든지역 ->'광역단체'단위  
임으로 데이터를 합치면 지역별로 비교하는데 어려움이 있었다.

**💡 해결방안**  
따라서 먼저 프로젝트의 지역 분류 기준을 통일시켰다.
- 서울 ->'구' 단위
- 경기도 ->'시' 단위
- 충청도 ->충남+충북+대전+세종
- 전라도 ->전남+전북
- 경상도 ->경남+경북
- 나머지 지역 -> 권역 기준

수집한 데이터를 실제 사용자가 쉽게 활용할 수 있도록 Streamlit으로 서비스를 구현하는 데 중점을 두었습니다.  
처음에는 데이터가 많다 보니 단순한 표 형태만으로는 원하는 정보를 빠르게 확인하기 어려웠습니다. 그래서 연도와 월, 지역을 선택할 수 있는 필터를 만들고, 선택한 조건에 따라 등록대수와 연료별 비율이 바로 변경되도록 구성했습니다.  
또한 숫자만 보여주는 것이 아니라KPI,Plotly,Pydeck를 활용해서 지역별·연료별 차이를 직관적으로 확인할 수 있도록 했습니다.  
마지막으로 데이터 누락으로 인해 일부 기간이 제대로 표시되지 않는 문제도 발생했는데, 데이터를 다시 정제하고 Streamlit의 선택 조건을 실제 데이터 기준으로 맞춰 문제를 해결했습니다.

### 👤 손혜민 - 전기차 보조금 데이터 크롤링

현대차 홈페이지에서 서울, 경기의 모든 시에 대해 모든 모델, 트림의 세제 전후, 보조금에 대한 데이터를 한꺼번에 뽑으려고 했습니다. 하지만 시/도, 시/군/구를 선택할때나 전기차의 종류를 선택하고 모델과 트림 선택을 할때 정확하게 선택하지 못하고 계속 목록을 넘기는 오류가 나타났습니다. 이러한 오류를 해결하기 위해 생성형 AI에게 해당 부분에 대한 HTML 코드를 div 코드까지 명확하게 주고, 모델 선택을 하고 트림 선택을 해야한다는 순서를 알려주었으며 트림 선택 화면으로 DOM이 전환되는 로딩시간을 주어 항목이 확실하게 선택할 수 있도록 코드를 수정하였습니다. 하지만 거듭 데이터 추출에 실패하여 팀원의 도움을 받아 서울과 경기지역의 모든 시에 대한 데이터를 따로 뽑고 합치는 방식을 사용하여 데이터를 추출하였습니다.

지역과 예산별 전기차와 내연기관 비교 페이지를 구현할때는 예산범위에 맞는 모델이 출력되지 않는 오류가 있었습니다. 이는 최종가가 예산범위 안에 들어오는지 비교가 되어야하는데 세제 혜택 후 금액으로 비교가 되고 있었습니다. 이를 최종가와 예산범위를 비교하는 코드로 수정하여 맞는 결과가 출력되도록 하였습니다.

### 👤 김지원

#### 🚗 -현대차 내연기관 크롤링
현대자동차 견적 페이지에서 카테고리 내 여러 차량 모델 및 세부 트림 데이터가 존재함에도, 스크립트 실행 시 첫 번째 슬라이드의 데이터 1건만 단발성으로 수집되고 나머지 목록이 누락되는 현상 발생했습니다. 이 문제를 해결하기 위해 캐러셀 동적 탐색 및 슬라이드 전수 순회했습니다.(옆으로 넘어가는 버튼을 누르는 과정까지 자동화함) 자동차 가격은 같은 차종이라도 트림별, 옵션별로 가격이 상이했습니다. 이 모든 경우의 수의 가격 데이터를 수집해야했지만 크롤링을 할 때 계속 누락되는 데이터가 생겼습니다. 각각 데이터를 누락없이 수집하기 위해 차량별 라디오 버튼 그룹(배기량, 변속기 등)을 트리 구조로 모델링을 했습니다. 그리고 재귀 함수(crawl_options)를 구축하여 비활성화된 옵션(is-disabled)을 자동으로 우회하고, 선택 가능한 모든 옵션 조합을 DFS 방식으로 완전 탐색했습니다.

#### ⚡ -충전소 데이터 불러오기
충전소 데이터는 크고 한 번에 api로 불러올 수 있는 양이 한정적이라 한번에 데이터를 가져올 수 없었습니다. 따라서  for 문을 사용해 한 페이지씩 데이터를 불러와 모든 데이터를 불러올 수 있었고 오류의 종류에 따라 프린트되는 문구를 다르게 해 오류가 떠도 즉각적으로 오류를 해결할 수 있게 했습니다.  워낙 데이터가 너무 커서 업로드에 문제가 생겨서 지역별로 데이터를 나누었습니다.

#### 🗺️ -충전소 웹페이지 구현
streamlit 패키지를 이용해 웹사이트를 구현했습니다.  지역별, 충전소 유형(사양), 지원 커넥터 규격, 최소 충전용량, 충전소명 또는 주소 검색 탭을 만들어 사용자에게 필요한 충전소를 찾기 쉽게 구현했습니다. 또한 팀원들에게 초기 지도에 색깔이 많아 들어가 한눈에 충전소가 어디에 있는지  한눈에 파악하기 어렵다는 점을 피드백을 받아 지도의 테마를 더 미니멀하고 충전소 표시 색과 대비되게 바꿨습니다.
